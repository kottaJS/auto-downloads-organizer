# Auto-Downloads Organizer for Windows

A silent, automated background utility for Windows that keeps your `Downloads` folder clean and organized.

[<img src="https://img.shields.io/badge/⬇️_Download_Latest_Release-ZIP-blue?style=for-the-badge&logo=windows&logoColor=white" height="40">](https://github.com/kottaJS/auto-downloads-organizer/archive/refs/heads/main.zip)

---

## 📁 Directory Structure

Automatically sorts loose files into the following categorized subfolders:

```text
Downloads/
├── [DOC] Documents/        (.pdf, .docx, .txt, .xlsx, .pptx)
├── [IMG] Images/           (.png, .jpg, .webp, .svg, .gif, .psd)
├── [VID] Videos/           (.mp4, .mkv, .mov, .webm)
├── [AUD] Audio/            (.mp3, .wav, .ogg, .flac)
├── [EXE] Installers/       (.exe, .msi, .bat, .ps1)
├── [ZIP] Archives/         (.zip, .rar, .7z, .iso)
├── [DEV] Code_and_Scripts/ (.js, .ts, .py, .html, .css, .json, .sql)
└── [MISC] Other/           (Uncategorized files)
```

---

## ⚡ 1-Click Installation

1. Download the project by clicking **[Download ZIP](https://github.com/kottaJS/auto-downloads-organizer/archive/refs/heads/main.zip)** and extract it.
2. Double-click `install.bat`.

The script will organize your Downloads folder immediately and configure a silent startup launcher to keep it organized automatically whenever Windows starts.

---

## 🗑️ Uninstallation

To completely remove the background automation and installed files:
- Double-click `uninstall.bat`.
